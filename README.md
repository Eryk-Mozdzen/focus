# FOCUS - BLDC motor control library

## Features

- FOC current loop implementation
- AB, AB+index, absolute encoder support
- [Sliding Mode Observer](https://www.mathworks.com/help/mcb/ref/slidingmodeobserver.html) method support
- [High Frequency Injection](https://www.sciencedirect.com/science/article/pii/S2214914723002155?fr=RR-2&ref=pdf_download&rr=a5664e15cb732783) method support
- automatic motor tunning
- C source code without external dependencies (even for `libm`)
